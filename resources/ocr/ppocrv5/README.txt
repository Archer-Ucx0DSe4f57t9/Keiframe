KeiFrame PP-OCRv5 Enemy Composition OCR Addon

Installation:
Extract this addon into the KeiFrame main program directory.

The installation must contain:
resources\ocr\ppocrv5\ch_PP-OCRv5_rec_mobile.onnx
resources\ocr\ppocrv5\ppocrv5_dict.txt

Restart KeiFrame after installation. Enemy Composition recognition will be
enabled automatically. No Python, RapidOCR, Tesseract, or extra runtime is
required.
